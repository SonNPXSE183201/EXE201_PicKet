## Implemented

- Login tracks the pending action independently: only the selected password/Google button spins; both buttons are disabled during a request, with a synchronous duplicate-press guard.
- Receipt camera keeps the left gallery icon and removes the duplicate gallery text button below the shutter. Manual entry remains available.
- Profile background refresh no longer sets full-page loading. Successful preference/profile writes merge into the current cached profile instead of forcing a refresh. Dashboard only blocks on initial data. Profile visibility persists immediately and rolls back on failure.
- Device-lock settings no longer unmount the navigation tree while authentication is busy. A genuinely locked session hides the mounted content and removes it from accessibility traversal. Account changes still reset the lock scope.
- Date inputs for bill create/edit, reconciliation, receipt purchase date, keepsake warranty/return dates and new subscriptions reuse MonthCalendar in a themed modal. Values remain ISO dates; labels display day/month/year. Month-only filters are not day pickers.
- Launcher adaptive icons use an inset drawable generated by an Expo config plugin. The in-app logo cannot shrink and uses contain sizing.
- Billing's unavailable-price message now describes a user action rather than internal tester configuration. Existing real offline/API failures remain visible; no blanket suppression of errors.
