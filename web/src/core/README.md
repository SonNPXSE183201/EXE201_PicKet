# Core Directory
Thư mục này chứa các thành phần dùng chung cho toàn bộ ứng dụng web.

Cấu trúc gợi ý:
- `components/`: UI components dùng chung (Button, Input, Modal, ...)
- `utils/`: Các hàm tiện ích dùng chung
- `constants/`: Biến hằng số
- `lib/`: Cấu hình thư viện (Supabase client, Axios, ...)
